# Сервис выполнения заказов (Fulfillment Service)

## Назначение и область применения

Отвечает за управление очередью заказов на кухне конкретного магазина: получив подтвержденный заказ,
сервис рассчитывает время приготовления на основе текущей загрузки магазина и технологических карт,
управляет системой отображения заказов на кухне (KDS) и фиксирует статус готовности заказа.
Этот сервис наиболее тесно связан с корпоративной целью **найма недорогого персонала с минимальной подготовкой**: 
он избавляет сотрудников от необходимости принимать заказы,
самостоятельно определять последовательность приготовления или оценивать время ожидания.

## Данные в ведении сервиса

**База данных Fulfillment** (PostgreSQL): очередь приготовления для каждого магазина,
статус готовности заказа, исторические данные о времени приготовления.

## Зоны ответственности

- Ведение актуальной очереди приготовления для каждого магазина (сортировка по времени подтверждения и приоритету)
- Расчет времени готовности/выдачи на основе технологических карт, текущей длины очереди и производственной мощности магазина
- Передача актуальной очереди в систему отображения заказов на кухне (через WebSocket)
- Фиксация статуса «готов» при подтверждении выполнения сотрудником магазина

## Предоставляемый API (синхронный)

| Метод | Эндпоинт | Описание | Потребители |
|---|---|---|---|
| GET | `/fulfillment/stores/{storeId}/queue` | Актуальная очередь приготовления (также передается через WebSocket) | Система отображения заказов на кухне (KDS) |
| POST | `/fulfillment/orders/{orderId}/ready` | Сотрудник отмечает заказ как готовый | Система отображения заказов на кухне (через Gateway) |
| GET | `/fulfillment/orders/{orderId}/eta` | Текущая оценка времени выдачи | Order Service, API Gateway |

## Публикуемые события (асинхронные — через шину событий)

| Событие | Условие возникновения | Ключевые поля полезной нагрузки | Потребители |
|---|---|---|---|
| `OrderReady` | Сотрудник отмечает заказ как выполненный | `orderId`, `storeId`, `fulfillmentType` | Order Service (обновление статуса); Delivery Dispatch Service (только при `fulfillmentType = delivery` для запуска процесса назначения курьера) |
