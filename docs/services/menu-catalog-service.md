# Сервис меню и каталога (Strapi)

## Назначение и область применения

Отвечает за то, *что именно можно заказать*: общенациональное базовое меню, определяемое корпорацией, и
локальные изменения для каждой франшизы (позиции, снятые с продажи, уникальные для конкретной точки добавки,
локализованные названия/переводы).

Предметная область в основном сводится к CRUD-операциям с контентом, админ-интерфейсу и локализации — функционалу, который
[Strapi](https://strapi.io/) предоставляет «из коробки».

## Данные в ведении сервиса

**База данных каталога** (PostgreSQL, полностью управляется Strapi): типы контента для
`menu-item` (общенациональные позиции), `store-menu-override` (изменения для франшизы) и
`prep-spec` (ингредиенты, этапы приготовления, расчетное время готовки), используемые
сервисом Fulfillment Service и системой отображения заказов на кухне (Kitchen Display System). Как и в случае с любым другим
сервисом, ни один внешний компонент не обращается к этой базе данных напрямую —
доступ осуществляется только через REST/GraphQL API самого Strapi.

## Зоны ответственности

- Ведение общенационального базового меню (управляется корпорацией через встроенный
  в Strapi менеджер контента — разработка отдельной админ-панели не требуется)
- Возможность для владельцев франшиз помечать позиции как недоступные или добавлять
  уникальные для своей точки товары (также через менеджер контента Strapi,
  с ограничениями согласно политике прав доступа — см. раздел «Нефункциональные требования»)
- Предоставление спецификаций приготовления и оценок времени готовки сервису Fulfillment Service
- Предоставление локализованного (переведенного) контента меню в зависимости от региона
  с использованием официального **плагина i18n** для Strapi — без написания собственного кода локализации

## Предоставляемый API (синхронный)

| Метод | Эндпоинт | Описание | Потребители | Кастомный или автогенерируемый? | |---|---|---|---|---|
| GET | `/api/menu/effective?storeId={id}` | Актуальное меню для конкретной точки (объединение общенационального меню и локальных изменений) | API Gateway (мобильное/веб-приложение) | **Кастомный** контроллер Strapi — единственный нестандартный запрос |
| GET | `/api/menu-items?locale={locale}` | Позиции общенационального меню (с локализацией) | API Gateway | Автоматически сгенерировано Strapi |
| PUT | `/api/menu-items/{id}` | Корпоративное изменение общенациональной позиции | Портал корпоративного администрирования (через Gateway) | Автоматически сгенерировано; доступ ограничено средствами Strapi (роли и права доступа, роль «корпоративный пользователь») |
| PUT | `/api/store-menu-overrides/{id}` | Владелец точки отмечает позицию как недоступную / добавляет локальную позицию | Портал владельца точки (через Gateway) | Автоматически сгенерировано; доступ ограничен кастомной политикой, сверяющей `tenantId` из JWT-токена вызывающего с `storeId` в записи об изменении |
| GET | `/api/menu-items/{id}?populate=prepSpec` | Инструкции по приготовлению и расчетное время приготовления | Сервис выполнения заказов (Fulfillment Service) | Автоматически сгенерировано |

## Публикуемые события (асинхронно — через шину событий)

| Событие | Условие возникновения | Ключевые поля полезной нагрузки | Потребители |
|---|---|---|---|
| `MenuItemAvailabilityChanged` | Изменение статуса наличия позиции в точке (появилась/закончилась) | `storeId`, `itemId`, `available` | Сервис заказов (отклоняет новые заказы на недоступные позиции) |

Strapi не поддерживает Kafka «из коробки», поэтому событие генерируется небольшим
мостом (bridge) типа «хук жизненного цикла — Kafka-продюсер», который срабатывает при создании или обновлении
записи `store-menu-override`.

## Потребляемые события / Зависимости

| Источник | Событие или API | Назначение |
|---|---|---|
| Сервис справочника франшиз и точек | `StoreHoursChanged` | Тот же процесс-мост подписывается на эту тему и вызывает API Strapi для автоматического скрытия позиций вне часов работы точки (если настроено соответствующее правило) |
