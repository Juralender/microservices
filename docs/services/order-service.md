# Сервис заказов (Order Service)

## Назначение и область ответственности

Отвечает за **полный жизненный цикл заказа**: корзина → оформление → подтверждение →
подготовка → готовность → передача курьеру / ожидание самовывоза → завершение / отмена.
Сервис управляет процессом оформления заказа, взаимодействуя с компонентами
ценообразования и акций (Pricing & Promotions), платежной системой (Payment)
и справочником франшиз и магазинов (Franchise & Store Directory). Он также выступает
в роли агрегатора, преобразующего детальные доменные события от других сервисов
(результат платежа, готовность блюд на кухне, статус курьера) в единый статус,
видимый клиенту.

## Данные в ведении сервиса

**База данных заказов** (PostgreSQL): заказы, товарные позиции, история переходов
состояний заказа, тип выполнения (самовывоз/доставка), назначенный магазин.

## Зоны ответственности

- Прием нового заказа (проверка того, что магазин открыт, а товары в наличии)
- Управление процессом оформления заказа: получение цены от сервиса Pricing & Promotions →
  запрос авторизации платежа у сервиса Payment (кроме случаев оплаты при получении) → подтверждение заказа
- Отслеживание переходов состояний заказа и предоставление текущего статуса клиенту
- Агрегация событий от смежных сервисов в единое событие `OrderStatusChanged` для отправки уведомлений

## Предоставляемый API (синхронный)

| Метод | Эндпоинт | Описание | Потребители |
|---|---|---|---|
| POST | `/orders` | Размещение нового заказа (запуск процесса оформления) | API Gateway (мобильное/веб-приложение) |
| GET | `/orders/{orderId}` | Текущий статус и детали заказа | API Gateway |
| GET | `/orders/{orderId}/timeline` | Полная история изменений статуса | API Gateway |
| POST | `/orders/{orderId}/cancel` | Отмена заказа (до начала приготовления) | API Gateway |

### Синхронные вызовы, выполняемые сервисом к смежным системам

| Целевой сервис | Вызов | Назначение |
|---|---|---|
| Franchise & Store Directory Service | `GET /stores/{id}/validate` | Проверка существования и режима работы магазина перед приемом заказа |
| Pricing & Promotions Service | `POST /pricing/quote` | Расчет итоговой стоимости (федеральные и локальные акции, налоги) |
| Payment Service | `POST /payments/authorize` | Авторизация онлайн-платежа (пропускается при оплате наличными/при получении) | 

## Публикуемые события (асинхронно — через шину событий)

| Событие | Условие возникновения | Ключевые поля полезной нагрузки | Потребители |
|---|---|---|---|
| `OrderPlaced` | Заказ принят, запущена сага | `orderId`, `storeId`, `items`, `fulfillmentType` | (внутренний этап саги) |
| `OrderConfirmed` | Платеж авторизован (или принят заказ с оплатой при получении) | `orderId`, `storeId`, `items`, `fulfillmentType` | Сервис выполнения заказа (Fulfillment Service) |
| `OrderStatusChanged` | Любое изменение статуса, видимое клиенту | `orderId`, `status`, `eta?` | Сервис уведомлений |

## Потребляемые события / Зависимости

| Источник | Событие | Назначение |
|---|---|---|
| Сервис платежей | `PaymentCaptured` / `PaymentFailed` | Перевод заказа в статус «Подтвержден» или «Отменен» |
| Сервис выполнения заказа | `OrderReady` | Перевод заказа в статус «Готов»; инициирование самовывоза или отправки |
| Сервис распределения доставки | `DriverAssigned` / `DeliveryStatusChanged` | Обновление статуса заказа (для заказов с доставкой) |
