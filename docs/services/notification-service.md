# Сервис уведомлений (легковесный адаптер поверх Novu)

## Назначение и область применения

Обеспечивает связь между доменными событиями и уведомлениями для клиентов и водителей
(SMS, push-уведомления, email). Сервис получает события об изменении статуса заказа из Kafka
и обращается к [Novu](https://novu.co/) для непосредственного формирования и отправки сообщения. Все
компоненты, которые раньше были частью кода — SDK провайдеров, шаблоны, выбор канала,
повторные попытки отправки — теперь находятся в Novu.

## Данные в ведении сервиса

Отсутствуют. История уведомлений и статусы доставки теперь хранятся в собственном
журнале активности Novu (доступном через API Novu для целей поддержки и отладки).

## Зоны ответственности

- Подписка на событие `OrderStatusChanged` в шине событий (Event Bus)
- Сопоставление внутреннего статуса заказа с соответствующим идентификатором рабочего процесса (workflow) в Novu
  и его запуск с передачей необходимых данных (ID клиента, ID заказа, статус, ETA)

## Предоставляемый API (синхронный)

Собственный API отсутствует — история и статусы уведомлений запрашиваются напрямую
через API Novu (с проксированием через Gateway, если это требуется инструментам поддержки).

### Вызовы, выполняемые сервисом к Novu

| Цель | Вызов | Назначение |
|---|---|---|
| Novu | `POST /v1/events/trigger` | Запуск рабочего процесса для конкретного изменения статуса заказа |

## Публикуемые события (асинхронные — через шину событий)

Отсутствуют — этот сервис является конечным потребителем; он не публикует доменные события.

## Потребляемые события / Зависимости

| Источник | Событие | Назначение |
|---|---|---|
| Order Service | `OrderStatusChanged` | Запуск соответствующего рабочего процесса в Novu | Сообщения, связанные с учетной записью или приветствием (например, при регистрации), намеренно вынесены за рамки данного решения: поскольку Keycloak — это готовое решение для управления идентификацией (IdP), процесс создания учетной записи не рассматривается как доменное событие в нашей шине сообщений. Если потребуется отправка приветственного сообщения, это можно реализовать через механизм SPI (слушатель событий) в Keycloak, вызывая Novu напрямую и минуя данный адаптер.
