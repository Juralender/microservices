# Сервис-справочник франшиз и точек продаж

## Назначение и область применения

Система, хранящая эталонные данные о том, **где находятся точки продаж, кто ими владеет, когда они открыты
и какова их пропускная способность**. Она отвечает на вопросы «существует ли эта точка / открыта ли она / может ли она
принять еще один заказ прямо сейчас» для всех остальных сервисов.

## Управляемые данные

**Store DB** (PostgreSQL): местоположение точек (адрес + геокоординаты), часы работы, привязка точек к владельцам франшизы,
настройки пропускной способности для каждой точки (макс. число одновременных заказов, средняя скорость приготовления).

## Зоны ответственности

- Справочник точек: поиск ближайших к клиенту открытых точек
- Управление часами работы и графиком работы в праздничные дни (редактируется через портал владельца точки)
- Управление принадлежностью: какой аккаунт владельца франшизы управляет конкретной точкой (или точками)
- Предоставление данных о текущей пропускной способности/настройках производительности для расчета
времени приготовления (используется сервисом обработки заказов — Fulfillment Service)
- Проверка того, что точка, указанная в заказе, действительно существует и открыта

## Предоставляемый API (синхронный)

| Метод | Эндпоинт | Описание | Потребители |
|---|---|---|---|
| GET | `/stores?near={lat,lng}` | Поиск ближайших открытых точек | API Gateway (мобильное/веб-приложение) |
| GET | `/stores/{storeId}` | Детальная информация о точке, часы работы, настройки мощности | API Gateway, Order Service |
| PUT | `/stores/{storeId}/hours` | Обновление часов работы точки | Портал владельца точки (через Gateway) |
| GET | `/stores/{storeId}/validate` | Проверка существования и текущего статуса (открыта/закрыта) | Order Service |

## Публикуемые события (асинхронные — через шину событий)

| Событие | Условие возникновения | Ключевые поля полезной нагрузки | Потребители |
|---|---|---|---|
| `StoreHoursChanged` | Владелец обновляет часы работы / график праздников | `storeId`, `newHours` | Menu & Catalog Service (корректировка доступности) |
