# Служба диспетчеризации доставки (Delivery Dispatch Service)

## Назначение и область ответственности

Отвечает за выполнение заказа на доставку после того, как кухня завершила его приготовление:
назначение ближайшего свободного водителя и отслеживание процесса доставки.

## Данные в ведении сервиса

**Dispatch DB** (PostgreSQL + Redis для оперативного поиска геоданных): доступность и местоположение водителей, назначения на доставку, история статусов доставки.

## Зоны ответственности

- Отслеживание статуса (онлайн/доступен) водителей в разрезе регионов
- Назначение ближайшего свободного водителя на готовый к доставке заказ
- Отслеживание статуса доставки (назначен → заказ забран → в пути → доставлен)
- Автоматизация назначения водителей для исключения роли диспетчера-человека (цель: снижение затрат на персонал)

## Предоставляемый API (синхронный)

| Метод | Эндпоинт | Описание | Потребители |
|---|---|---|---|
| POST | `/drivers/{driverId}/availability` | Водитель переходит в статус онлайн/офлайн | Приложение водителя (через Gateway) |
| PUT | `/drivers/{driverId}/location` | Передача текущего местоположения | Приложение водителя (через Gateway) |
| POST | `/deliveries/{orderId}/confirm-pickup` | Водитель подтверждает получение заказа | Приложение водителя |
| POST | `/deliveries/{orderId}/confirm-dropoff` | Водитель подтверждает доставку | Приложение водителя |
| GET | `/deliveries/{orderId}` | Текущий статус доставки и назначенный водитель | API Gateway |

### Синхронные вызовы, выполняемые сервисом к другим компонентам

| Целевой сервис | Вызов | Назначение |
|---|---|---|
| Directions & Mapping Service | `GET /directions/route` | Маршрут и расчет времени прибытия (ETA) до адреса клиента с учетом пробок |

## Публикуемые события (асинхронные — через шину событий)

| Событие | Условие возникновения | Ключевые поля полезной нагрузки | Потребители |
|---|---|---|---|
| `DriverAssigned` | Водитель назначен на доставку | `orderId`, `driverId`, `etaMinutes` | Order Service |
| `DeliveryStatusChanged` | Смена статуса: забран / в пути / доставлен | `orderId`, `status` | Order Service |

## Потребляемые события / Зависимости

| Источник | Событие | Назначение | |---|---|---|
| Служба фулфилмента | `OrderReady` (с фильтром `fulfillmentType = delivery`) | Запуск процесса назначения водителя |
