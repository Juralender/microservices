# Сервис ценообразования и акций (Pricing & Promotions Service)

## Назначение и область действия

Вычисляет итоговую стоимость заказа: базовые цены на товары, общенациональные ежедневные спецпредложения,
локальные (для конкретного магазина) ежедневные спецпредложения, налоги и валюту — для любого региона присутствия компании.

## Данные в ведении сервиса

**База данных акций** (PostgreSQL): базовые цены на товары, общенациональные акции (управляются корпорацией, действуют везде), 
локальные акции (управляются владельцем, действуют в одном магазине), правила налогообложения и настройки валюты для каждого региона.

## Зоны ответственности

- Управление общенациональными ежедневными спецпредложениями/акциями (уровень корпорации)
- Управление локальными ежедневными спецпредложениями/акциями (уровень владельца франшизы)
- Расчет стоимости корзины: базовая цена → применение лучших из доступных общенациональных и локальных акций → применение регионального налога → возврат суммы в местной валюте
- Предоставление ленты данных о спецпредложениях текущего дня для отображения в клиентских приложениях

## Предоставляемый API (синхронный)

| Метод | Эндпоинт | Описание | Потребители |
|---|---|---|---|
| POST | `/pricing/quote` | Расчет итоговой стоимости корзины для конкретного магазина | Order Service, API Gateway (предпросмотр корзины) |
| GET | `/promotions?storeId={id}` | Активные общенациональные и локальные акции для магазина | API Gateway (мобильное/веб-приложение) |
| PUT | `/promotions/national` | Создание/редактирование общенациональной акции корпорацией | Портал администрирования корпорации (через Gateway) |
| PUT | `/promotions/stores/{storeId}` | Создание/редактирование локальной акции владельцем | Портал владельца магазина (через Gateway) |

## Публикуемые события (асинхронные — через шину событий)

| Событие | Условие возникновения | Ключевые поля полезной нагрузки | Потребители |
|---|---|---|---|
| `PromotionActivated` | Запуск новой общенациональной или локальной акции | `scope`, `storeId?`, `promoId` | (аналитика / для будущего использования) |

## Потребляемые события / Зависимости

Нет синхронных зависимостей, кроме обработки вызова `POST /pricing/quote`;
Реализация собственной логики сервиса не зависит от других сервисов.
