## 1. Клиент оформляет заказ для самовывоза и получает маршрут

Юзер открывает **мобильное приложение**, просматривает меню ближайшей к нему точки франшизы
и добавляет в корзину сэндвич BLT и напиток. Приложение автоматически применяет действующую сегодня **общенациональную акцию**
(«Бесплатные чипсы к любому комбо-набору») совместно с **локальной акцией**,
настроенной владельцем точки («Скидка 10% при заказе до 11:00»). Юзер оплачивает заказ онлайн сохраненной картой,
а приложение показывает **время готовности** (рассчитанное с учетом текущей
загруженности кухни), а также **пошаговый маршрут и информацию о пробках**
по пути к заведению. Когда заказ готов, юзер получает push-уведомление.

*Задействованные компоненты: Мобильное приложение → API-шлюз → Сервисы: «Меню и каталог», «Цены и акции»,
«Заказы», «Платежи», «Обработка заказов», «Маршруты и карты», «Уведомления».*

## 2. Клиент заказывает доставку с оплатой наличными при получении

Клиент использует **веб-приложение** на ноутбуке, оформляет заказ с доставкой и выбирает
опцию «оплата при получении» вместо онлайн-оплаты. Сервис заказов подтверждает
заказ без предварительного списания средств. Сервис обработки заказов
передает заказ на кухню; после готовности сервис диспетчеризации доставки
назначает ближайшего свободного курьера, который использует сервис маршрутов и карт
(через приложение для курьеров), чтобы добраться до адреса клиента. Курьер
принимает наличные и отмечает заказ как оплаченный в приложении; эти данные
сверяются с реестром платежного сервиса.

*Задействованные компоненты: Веб-приложение → Сервис заказов → Сервис обработки заказов → Сервис диспетчеризации доставки
→ Приложение для курьеров → Сервис маршрутов и карт → Платежный сервис
(сверка оплаты при получении).*

## 3. Владелец франшизы управляет локальным спецпредложением дня

Бизнесмен, владеющий тремя точками франшизы, входит в **портал владельца
заведения**. Он устанавливает специальное предложение «Купи один — получи второй в подарок»
для одной из своих точек (действует сегодня с 14:00 до 16:00) и обновляет график работы этого 
заведения с учетом предстоящего праздника. 
Эти изменения касаются только его франшизных точек и не затрагивают заведения других владельцев или общенациональное меню.

*Задействованные компоненты:
Портал владельца точки → API-шлюз → Сервис ценообразования и акций (локальные спецпредложения), Сервис справочника франшиз и точек (график работы).*

## 4. Отдел корпоративного маркетинга запускает общенациональную акцию

Команда корпоративного маркетинга использует **Портал корпоративного администрирования** для
планирования общенациональной акции («Бесплатная доставка по вторникам»), 
которая становится видимой на витринах всех франшизных точек с полуночи,
а также просматривает сводные данные об объеме заказов по всей сети.

*Задействованные компоненты:
Портал корпоративного администрирования → API-шлюз → Сервис ценообразования и акций (общенациональные спецпредложения), Сервис меню и каталога (позиции общенационального меню).*

## 5. Персонал точки выполняет заказы, пройдя минимальное обучение

Новый сотрудник, работающий на кассе неполный день, не имеет опыта работы с POS-системами.
Заказы просто появляются на **Кухонном дисплее** в той последовательности, в которой их нужно готовить;
для каждого заказа отображаются таймер обратного отсчета и инструкции по приготовлению,
полученные из Сервиса меню и каталога. По завершении работы сотрудник нажимает кнопку «Готово» —
не требуется ни ручного приема заказов, ни расчета цен, ни навыков общения по телефону, 
что соответствует корпоративной стратегии найма персонала с минимальной подготовкой и невысокой стоимостью оплаты труда.

*Задействованные компоненты:
Кухонный дисплей → API-шлюз → Сервис выполнения заказов (обрабатывает событие `OrderConfirmed`, публикует `OrderReady`).*

## 6. Курьер выполняет доставку

Курьер открывает **Приложение для водителей**, получает задание на доставку,
переданное Сервисом диспетчеризации доставки, и запускает навигацию. 
При этом вызывается Сервис маршрутизации и карт (использующий внешний картографический сервис с учетом дорожной обстановки)
для построения кратчайшего маршрута. По прибытии курьер подтверждает передачу заказа; 
это обновляет статус заказа и инициирует отправку клиенту уведомления о том, что заказ доставлен. 

*Задействованные компоненты:
приложение для водителей → служба диспетчеризации доставки → служба маршрутизации и карт → служба уведомлений (через шину событий).*

## 7. Выход на зарубежный рынок: оформление заказа на новом рынке

После того как материнская компания запускает первую международную франшизу, 
клиент на новом рынке открывает мобильное приложение и видит меню, акции и цены, 
уже адаптированные (с учетом валюты, налогов и перевода названий позиций) службами «Ценообразование и акции» (Pricing & Promotions)
и «Меню и каталог» (Menu & Catalog). 
При этом не требуется вносить изменения в службы обработки заказов, 
платежей или другие ключевые компоненты системы — достаточно лишь добавить региональные настройки.

*Задействованные компоненты:
служба «Меню и каталог» (локализация), служба «Ценообразование и акции» (валюта и налоги в зависимости от региона), служба платежей (платежный шлюз, соответствующий требованиям региона).*

## 8. Существующий канал приема заказов по факсу продолжает работать без изменений

Постоянный клиент по-прежнему может позвонить в магазин и отправить заказ по факсу, как и раньше.

**Устаревшая система приема заказов по факсу** (Legacy Fax Ordering System) остается полностью обособленным каналом, 
требующим ручной обработки: сотрудники магазина вручную вводят данные заказа, 
если хотят отразить его в новой системе, либо просто готовят заказ напрямую.
Ни один микросервис не интегрируется с системой факсимильной связи.
